\# 🏥 Patient Risk Prediction System



A machine learning web app that predicts patient health risk using clinical data.



\## 🚀 Features

\- Login / Signup (Admin \& Patient)

\- Risk prediction using ML models

\- Risk levels: Low / Medium / High

\- Suggestions based on risk

\- Model evaluation (ROC, Accuracy, etc.)

\- Upload CSV for batch prediction

\- History tracking (Admin \& Patient)



\## 🧠 Models Used

\- Logistic Regression

\- Decision Tree

\- Random Forest

\- Gradient Boosting
